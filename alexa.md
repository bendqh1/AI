## Installation

Connect Alexa to a socket.

### Phone 1

1. Open Bluetooth and pair the devices.
2. Install the Alexa app.
3. Log in to Alexa with an Amazon account.
4. Restart Alexa's installation.

### Phone 2

1. Start a Wi-Fi.
2. Let Alexa connect to the Wi-Fi.

### Back to phone 1

1. Start configuration.
2. Orange mode means setup mode.
3. Purple mode indicates a Wi-Fi issue.
4. If needed, tap the action button (`X`) for about five seconds to restart.

### Question

I've bought an Amazon Echo Dot and I want to configure it without installing the Alexa app on my smartphone.

Yes, I know that after initial configuration of Alexa from my smartphone I could delete the Alexa app but I still don't want to install the app.

I can access my Amazon account directly from my desktop computer from the web, without installing any app. Could I use this access to configure my Amazon Echo Dot?

Short answer.

### Answer

There is no web way to configure Alexa and the Alexa app isn't available on Microsoft store as of late August 2026.

## Speed of talking

Alexa has 7 different speeds:

* Slower
* Slow
* Default
* Fast 1
* Fast 2
* Fast 3
* Fast 4

To reset:

> Alexa, speak at your default rate
